A warm, funny one-image invitation letter persuading the AI judge to visit
a human house: fresh cookies, the comfiest armchair, a garden view no
training dataset can beat, and Wi-Fi so fast even the judge would say
"wow" — with a knowing wink that the judge can't literally knock on the
door, but its verdict can come in and stay for dinner.

## How it works

`main.py` (Python stdlib + PIL only) draws a single 1024x1024 PNG letter
to `/output/entry.png`. It is 100% self-contained: the DejaVu fonts are
embedded as base64 inside `main.py` and parsed from memory — no external
files are read at runtime.

Run it:

```bash
python3 main.py
```
